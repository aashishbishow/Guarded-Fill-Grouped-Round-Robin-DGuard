# Complete Source Manifest — Dining Philosophers Paper

This package is the whole-paper source/reproducibility bundle.

## Important answer

`native/final_native_threads.cpp` is **not the code for the entire paper**.
It is the exact C++17 source for the final 960-run native-thread evidence only.

The paper contains several separate empirical/formal components, mapped below.

## 1. Current manuscript

- `paper/paper.pdf` — current editorially corrected manuscript.
- `paper/paper.tex` — LaTeX source.
- `paper/references.bib` — bibliography.

## 2. Synchronous simulator and formal/model verification

Source:
- `simulator/experiment.py`
- `simulator/verify_stress.py`
- `simulator/make_figures.py`
- `simulator/Dining_Philosophers_FullScale_Reproduction.executed.ipynb`

These implement/cover:
- fixed GRR;
- RotatingGreedy;
- Age-MWIS exact cycle DP;
- SingleWaiter;
- Guarded-Fill GRR;
- the 720-run core simulator matrix;
- canonical N=5 experiments;
- N=10,001 stress experiments;
- GRR structural/opportunity-gap verification;
- Age-MWIS brute-force verification;
- selector scaling through N=1,000,000.

Exact simulator outputs used by the manuscript are under `data/simulator/`.

`analysis/analyze_simulator.py` recomputes the main paired statistics and the
three-way GF-GRR / GRR / Age-MWIS trade-off tables from the raw simulator data.

## Recommended reproduction order

1. Create Python environment:
   `pip install -r requirements.txt`
2. Simulator:
   run `simulator/experiment.py`, then `simulator/verify_stress.py`.
   The historical scripts use `/mnt/data/dpp_research` as their output/import
   location; either create that path or adjust those path constants.
3. Recompute simulator statistics:
   `python analysis/analyze_simulator.py`
4. Compile native final source:
   `g++ -O3 -std=c++17 -pthread native/final_native_threads.cpp -o native_final`
5. For native x86_64/ARM64 replication, use
   `workflows/reproduce_final_native.yml`.
6. Recompute final native summaries/statistics/figures:
   `python analysis/analyze_final_native.py`
